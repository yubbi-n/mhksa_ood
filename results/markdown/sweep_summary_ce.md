# CIFAR10 CE · 범위 × PCA 비율 스윕

ResNet18 CE · H = 10 · seed 5개 평균 · FPR95 (OOD 5개 평균, ↓)

- 범위: median γ × [0.3, 2 / 3 / 5 / 7 / 10 / 15 / 20 / 30]
- 1단계 PCA 비율 (head별 PCA): 0.6 / 0.7 / 0.8 / 0.9 / 0.95
- 2단계 PCA 비율 (MHKSA만): 0.9 / 0.95 / 0.99 / 1.0 (1.0 = 2단계 없음)
- 최적값은 테스트 OOD로 고른 값 → **분석용** (성능 주장 X)
- 기존에 돌린 조합은 기존 결과와 모두 일치 (스크립트 검증)

## 경향

- **범위는 넓을수록 좋음**: ×2 · ×3이 가장 나쁨
- **MHKSA는 ×10부터 평평**: ×10 ~ ×30 최고값 27.39 → 26.99 (차이 0.4%p, ×10의 seed 표준편차 0.29 수준)
- **앙상블은 ×30까지 계속 좋아짐**: ×15부터 튜닝 KPCA(28.63)를 넘음. 1단계 최적은 항상 0.8
- **범위가 넓을수록 MHKSA의 1단계 최적 비율이 낮아짐**: ×3 0.95 → ×10 0.9 → ×15 · ×20 0.8 → ×30 0.7
- **1단계 비율이 너무 낮으면 크게 나빠짐**: 0.6은 모든 방법에서 나쁨, 0.7은 좁은 범위에서 나쁨
- **2단계 비율은 영향이 작음**: 좋은 구역에서 0.9 ~ 1.0 사이 차이 대부분 0.5%p 이내
- **PCA 비율이 기준선을 크게 바꿈**: median KPCA가 비율 0.8에서 40.28, 0.95에서 33.67

## 결론

- **CIFAR10 CE 최적 구역 = 범위 ×10 이상 + 1단계 0.7 ~ 0.9** (구역 안에서는 설정을 바꿔도 결과가 거의 같음)
- 원래 쓰던 설정(×10, 0.9, 0.9 = 27.39)이 이미 최적 구역 안 → 새로 찾은 최고(×30, 0.7, 0.9 = 26.99)와 사실상 같음
- 앙상블은 범위를 ×15 이상으로 넓히면 튜닝 KPCA를 넘음 (×30에서 27.92)
- 비율을 맞춘 median KPCA(33.67) 대비 MHKSA 이득은 약 6.7%p

## 주의

- CE 결과만. SupCon은 범위를 넓히면 MHKSA가 나빠졌으므로 넓은 범위가 모든 백본에 좋다고 할 수 없음
- 튜닝 KPCA(γ = 2)는 비율 0.8로만 측정 → 비율별 측정 필요 (공정한 비교)
