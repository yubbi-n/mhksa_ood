- 백본: torchvision ResNet50 IMAGENET1K_V1 (top-1 76.13%), ID train 200장/클래스 = 200,000장
- OOD: iNaturalist, SUN, Places, Textures (OOD별 FPR95를 구한 뒤 평균)
- 원논문 CoRP 설정: M 4096, PCA 비율 0.5
- MHKSA: r1 = r2 = √0.5 ≈ 0.71 (r1 × r2 ≈ 0.5, 원논문 비율과 맞춤)

- H = 1~10, seed 5개 (mean ± std). γ와 비율 모두 test OOD로 고르지 않은 고정 설정

## 정리
1. **MHKSA가 γ 튜닝 없이 원논문 튜닝 KPCA와 같은 수준**: 48.43 ± 0.23 vs 48.60 (재현 48.63). median KPCA(69.22) 대비 −20.8.
2. **H ≥ 3부터 48.3~48.7로 안정** → H를 크게 고민할 필요 없음.
3. **범위가 결정적**: ×3 61.81 → ×10 48.43. 범위가 튜닝 γ(=3)를 포함해야 함. CIFAR-10의 "범위가 가장 중요, ×10 이상에서 수렴"과 같은 결론.
4. **섞는 것 자체의 이득은 없음**: MHKSA 48.43 ≈ best head 48.42. 다만 best head는 test OOD로 고른 값이고, MHKSA는 고르지 않고 같은 성능 → "γ를 고르지 않아도 되는 것"이 이점.
5. **Ensemble은 ImageNet에서 약함** (60.00): γ가 작은 head들을 같은 가중치로 섞어서 성능이 깎임.
6. 참고(분석용): MHKSA e2만 쓰면 47.59로 가장 낮음. 보고 설정은 아님.
