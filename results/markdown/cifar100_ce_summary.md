# CIFAR-100 (ResNet18, CE)

## 공통 설정
- 백본: ResNet18 (ood-kernel-pca의 resnet18_cifar), CIFAR-100으로 직접 학습 (100 epoch, test acc 77.87%)
- ID train 50,000장 / ID test 10,000장
- OOD: SVHN, LSUN, iSUN, Texture, Places365 (CIFAR-10과 같은 OOD 세트, OOD별 FPR95를 구한 뒤 평균)
- CoRP 설정: CIFAR-10과 동일 (M 2048, PCA 비율 0.8)
- MHKSA: r1 = r2 = 0.9 (r1 × r2 ≈ 0.8)
- head γ = median γ × geomspace(0.3, 범위, H)
- H = 1~10, seed 5개 (mean ± std)
- γ와 비율 모두 test OOD로 고르지 않은 고정 설정
- 원논문에 CIFAR-100 결과가 없어 튜닝 KPCA 기준이 없음 → best head(test OOD로 선택)를 참고값으로 사용

## 결론
1. **범위를 넓히면 크게 좋아짐**: MHKSA ×3 71.44 → ×10 66.75 → ×20 66.02
2. **×10 이후로는 거의 변화 없음** → CIFAR-10·ImageNet과 같은 결론
3. **×10 이상에서 MHKSA가 best head(test OOD로 선택)보다 좋음**: 섞는 이득이 나타난 유일한 데이터셋
4. **Texture는 범위를 넓혀도 그대로** (MHKSA 55~56, median KPCA 53.19보다 약간 나쁨)
