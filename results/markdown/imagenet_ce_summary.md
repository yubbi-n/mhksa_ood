# ImageNet-1K (ResNet50, CE)

## 공통 설정
- 백본: torchvision ResNet50 IMAGENET1K_V1 (top-1 76.13%), ID train 200장/클래스 = 200,000장
- OOD: iNaturalist, SUN, Places, Textures (OOD별 FPR95를 구한 뒤 평균)
- 원논문 CoRP 설정: M 4096, PCA 비율 0.5
- MHKSA: r1 = r2 = √0.5 ≈ 0.71 (r1 × r2 ≈ 0.5, 원논문 비율과 맞춤)
- head γ = median γ (≈0.52) × geomspace(0.3, 범위, H)
- H = 1~10, seed 5개 (mean ± std)
- γ와 비율 모두 test OOD로 고르지 않은 고정 설정

| 범위 | head γ | 원논문 튜닝 γ=3 포함 |

| ×3 | 0.16 ~ 1.56 | X |
| ×10 | 0.16 ~ 5.2 | O |
| ×20 | 0.16 ~ 10.4 | O |

## 결론
1. **범위가 튜닝 γ를 포함하면 MHKSA가 튜닝 KPCA 수준**: ×3 61.81 → ×10 48.43 → ×20 48.02
2. **×10 이후로는 거의 변화 없음** → CIFAR-10의 "×10 이상에서 수렴"과 같은 결론
3. **γ를 고르지 않아도 됨**: test OOD로 고른 best head와 같은 성능
4. **Ensemble은 ImageNet에서 약함** (59~60): γ가 작은 head를 같은 가중치로 섞어 손해
